# Инструмент проведения аудита (СМК) практических рекомендаций Росздравнадзора
Инструмент «ВККиБМД» — эффективное решение для реализации обязательного требования в рамках 323-ФЗ «Об основах охраны здоровья граждан», ст. 90. Внутренний контроль качества и безопасности медицинской деятельности
Облачный инструмент «ВККиБМД» - готовое цифровое решение для эффективного проведения аудита системы менеджмента качества (СМК) в медицинских организациях
Инструмент помогает автоматизировать внутренний контроль качества и выстроить управление процессами в соответствии со стандартами качества и Практическими рекомендациями Росздравнадзора
